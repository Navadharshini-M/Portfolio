# Nava Dharshini M — Front-End Developer Portfolio & Digital Resume

A production-quality personal portfolio and digital resume designed with editorial typography, responsive architecture, and modern front-end tooling.

- **Uyirsaaru:** [uyirsaaru.com](https://uyirsaaru.com)
- **Sarvam Care Hospital:** [sarvamcarehospital.in](https://sarvamcarehospital.in)

## 🛠️ Tech Stack
- **Framework:** React 18 (TypeScript)
- **Bundler:** Vite
- **Styling:** Tailwind CSS (Custom Sage/Olive/Lime palette)
- **Typography:** Plus Jakarta Sans
- **Icons:** Lucide React
- **Resume Modal:** PDF Viewer & ATS-friendly one-page download

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Navadharshini-M/Portfolio.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deploy to Vercel
This repository is pre-configured with `vercel.json` for automatic zero-configuration Vite SPA deployment on Vercel.
